WAS IST DRAGEND?

Dragend ist ein eigenes Menü für deinen MiSTer. Statt dich im MiSTer-Menü durch Ordner zu klicken, siehst du deine Spiele nach Systemen sortiert – mit Cover, Erscheinungsjahr und Beschreibung – und startest sie mit einem Tastendruck. Beendest du ein Spiel, bist du wieder im Frontend.
Dragend verändert am MiSTer selbst nichts: kein Kernel, kein Image, keine Cores. Es ist ein Programm, das neben dem MiSTer läuft. Deinstallieren geht mit einem Skript, danach ist alles wie vorher.
IN DREI SCHRITTEN INSTALLIERT
1
Frontend_Install.sh von der Projektseite herunterladen (Rechtsklick → Speichern unter).
2
Die Datei nach /media/fat/Scripts/ kopieren – per WinSCP/FTP oder mit der SD-Karte am PC.
3
Am MiSTer im Menü Scripts → Frontend Install ausführen. Das Skript lädt alles Weitere selbst, richtet den Autostart ein und startet den MiSTer neu.
Der allererste Start dauert länger. Das Frontend liest dabei einmal alle Spiele und den Arcade-Ordner ein und zeigt den Fortschritt. Danach startet es in rund zwei Sekunden.
DER ERSTE START: DIE EINRICHTUNG
Beim ersten Start führt dich eine kurze Einrichtung durch sieben Fragen: Sprache, Bildschirm (HDMI-Fernseher oder Röhre), Zeitzone, RetroAchievements, Boxart und Spieleinfos laden, dann werden deine Spiele gesucht. Mit OK geht es weiter, mit Esc überspringst du einen Schritt. Alles lässt sich später ändern – die Einrichtung startest du jederzeit neu unter System → Info → Einrichtung erneut starten.
WO DEINE SPIELE LIEGEN MÜSSEN
Genau dort, wo der MiSTer sie auch sucht: unter /media/fat/games/<System> (also z.B. games/SNES), auf einem USB-Laufwerk unter games/<System> oder auf einem Netzlaufwerk. Unterordner sind erlaubt und erscheinen im Frontend als Ordner. Arcade-Spiele kommen aus /media/fat/_Arcade.

DIE HAUPTSEITE

Nach dem Start siehst du die Hauptseite: eine Liste von Kategorien. Was es dort gibt, hängt davon ab, was auf deiner Karte liegt.
Weiterspielen
Dein zuletzt gespieltes Spiel, das du noch nicht als durchgespielt markiert hast – ein Druck, und es geht weiter.
Zuletzt gespielt
Die Spiele, die du zuletzt gestartet hast, das neueste oben.
Favoriten
Alles, was du mit L2 / F8 markiert hast.
Die Systeme
Eine Kategorie je System, für das Spiele da sind – SNES, Mega Drive, PlayStation und so weiter. Systeme ohne Spiele erscheinen nicht.
Die Computer
Commodore 64, Amiga 500, Amstrad CPC und DOS (ao486) – mehr dazu auf Seite 10.
Arcade
Die Automaten aus dem _Arcade-Ordner, mit allen Unterordnern.
Sammlungen
Automatische Zusammenstellungen quer über alle Systeme.
RA-Erfolgsjäger
Spiele in deiner Sammlung mit offenen RetroAchievements-Erfolgen (wenn RetroAchievements eingerichtet ist).
Zufalls-Zock
Keine Lust zu suchen? Das Frontend zieht drei Spiele zur Wahl – ohne Wiederholung, bis alle einmal dran waren. Vom 1.12. bis 6.1. heißt er Wichtel-Zock.
System
Alle Einstellungen, Statistiken, Wartung – dazu deine Scripts und die Core-Ordner. Steht immer ganz unten.
DIE HAUPTSEITE NACH DEINEM GESCHMACK
Sortieren und ausblenden: System → Optionen → Hauptseite, oder im Kontextmenü (X / F1) Diese Kategorie ausblenden. Sechs Ansichten (F10 / Select+Y): Liste, Raster, Galerie – und auf HDMI zusätzlich Kachelwand, Dashboard und Karussell.
Attract-Modus: Rührst du eine Weile nichts an, zeigt das Frontend Spiele mit Cover als Bildschirmschoner. OK startet das gezeigte Spiel, links/rechts wechselt das System, jede andere Taste weckt nur auf. Einstellbar unter System → Optionen.

SPIELE STARTEN UND FINDEN

EIN SPIEL STARTEN
Kategorie öffnen, Spiel auswählen, A / Enter. Bei Systemen, für die es mehrere Cores gibt, fragt das Frontend kurz nach: Standard-Core, RetroAchievements-Core (mit echten Erfolgen) oder Netplay-Core – je nachdem, was installiert ist. Spiele mit mehreren Discs stehen als ein Eintrag in der Liste; beim Starten wählst du die Disc.
VIER ANSICHTEN FÜR DIE SPIELELISTE (F10 / SELECT+Y)
Liste (Namen links, großes Cover rechts), Raster (viele Cover nebeneinander), Galerie (großes Cover mit Beschreibung, Nachbarn darunter) und Coverflow (nur HDMI: das Cover in der Mitte, die Nachbarn kleiner daneben). Die Taste probiert aus; die Vorgabe für alle stellst du unter System → Anzeige & Sound → Ansicht Spieleliste.
DAS KONTEXTMENÜ (X / F1)
Spiel-InfosDer Steckbrief: Cover, Jahr, Genre, Hersteller, deine Spielzeit und die Beschreibung auf einer Seite.
Anleitung anzeigenNur wenn für dieses Spiel eine Anleitung auf der Karte liegt.
Favorit / durchgespieltMarkierungen setzen und wieder entfernen.
Core-Fassung für dieses SpielEin bestimmter Core nur für genau dieses Spiel (wenn es mehrere gibt).
Suchen, Filter, BuchstabeSchnell zum gesuchten Spiel – die Suche findet auch Wörter mitten im Namen.
Ansicht wechselnWie F10.
Zufälliges Spiel / FavoritStartet ein zufälliges Spiel bzw. einen zufälligen Favoriten.
Diesen Eintrag ausblendenVersteckt ein Spiel oder einen Ordner. Zurückholen unter System → Anzeige & Sound → Ausgeblendete Einträge.
WOHER DIE COVER KOMMEN
Das Frontend nimmt, was es findet, in dieser Reihenfolge: deine eigenen Cover, dann die Artwork-Datenbank von Update All (/media/fat/docs, über Extra Content → Game Artwork DBs), und für den Rest lädt System → Wartung → Boxarts nachladen die fehlenden aus dem Netz. Was Update All schon geliefert hat, wird dabei erkannt und nicht noch einmal geladen.
Damit alles flüssig läuft: einmal System → Optionen → Miniaturen vorbereiten laufen lassen. Das rechnet alle Cover im Voraus auf die passende Größe – danach ist jedes Cover sofort da, auch nach einem Neustart. Dauert einige Minuten, lässt sich mit jeder Taste abbrechen und später fortsetzen.

ANZEIGE & SOUND: AUSSEHEN

Alle Einstellungen findest du auf der Hauptseite ganz unten unter System. Ein Eintrag zeigt immer den aktuellen Wert; OK schaltet weiter. Hier der Ordner System → Anzeige & Sound, erster Teil:
Menü-Video: HDMI / CRTFür Röhrenfernseher: stellt das Bild des MiSTer-Menüs auf 15 kHz um. Wirkt nach einem Neustart.
FarbschemaDie Farben des Frontends. Mit als eigenes Schema speichern und bearbeiten baust du dir dein eigenes.
Boot-LogoWelches Logo beim Start erscheint: Dragend, Cirdan, jedes Mal ein zufälliges, oder neutral.
SchriftDie eigene Schrift des Frontends oder eine der MiSTer-Schriften aus /media/fat/font.
FeinheitenKleine Zierelemente: Scrollbalken, Akzentbalken, Trennlinie. Aus = ruhigeres Bild.
HintergrundbildEin eigenes Bild statt der dunklen Fläche. Bilder legst du nach /media/fat/frontend/backgrounds.
LochmaskeLegt ein Röhren-Muster über das Bild – aus MiSTers eigenem Ordner /media/fat/Shadow_Masks.
Rand seitlich / oben-untenAbstand zum Bildrand. Hochstellen, wenn deine Röhre am Rand etwas abschneidet.
Menü-Auflösung: voll / halbNur HDMI: halbe Auflösung macht das Frontend schneller, das Bild etwas weicher. Nach Neustart.
Markierungs-SchimmerDie Auswahl pulsiert leicht. Aus = feste Hervorhebung.
Cover verkleinern: weich / scharfWeich rechnet gemittelt, scharf behält den Pixel-Look – auf der Röhre oft schöner.
Fremdes Artwork/DatenCover, Jahr und Beschreibungen aus der Update-All-Datenbank verwenden. Füllt nur Lücken, ersetzt nie deine eigenen Cover. Empfohlen: an.
Cover vom Basis-Spiel erbenHacks und Übersetzungen ohne eigenes Cover zeigen das Cover des Originalspiels.
Grundregel: Bei allem, wo „nach Neustart“ dabeisteht, ändert sich das Bild erst nach einem Neustart des MiSTer. Alles andere wirkt sofort.

DIE COMPUTER MIT SPIELEN

Seit Version 5.1 stehen vier Heimcomputer als eigene Kategorien auf der Hauptseite – mit Gerätefoto und den Spielen, die auf deiner Karte liegen.
Commodore 64 Spiele aus games/C64 (z.B. die One-Load-Sammlung) starten direkt mit dem C64-Core.
Amiga 500 Beim Öffnen wählst du: AmigaVision starten (das Spiel wählst du dann im AmigaVision-Menü) oder ADF-Disketten, wenn welche installiert sind.
Amstrad CPC Disketten-Abbilder aus games/Amstrad mit dem CPC-Core.
DOS (ao486) Die 0MHz-Sammlung für den ao486-Core. Fehlen einem Spiel Dateien, sagt das Frontend das beim Start.
WAS DER AMIGA BRAUCHT
Den Minimig-Core, ein Kickstart-ROM und – für AmigaVision – die beiden Festplatten-Dateien AmigaVision.hdf und AmigaVision-Saves.hdf. Die trägst du einmal im MiSTer-OSD des Amiga-Cores als Festplatten ein. Bleibt der Amiga beim Kickstart-Bild stehen, fehlt meistens genau das.
Computer-Check: System → Wartung → Computer-Check geht alle vier Computer durch und nennt, was fehlt – Core, ROM, Festplatte oder Spieldateien.
Tastatur bereithalten: Viele Computerspiele wollen eine Tastatur (Leertaste, F-Tasten, Namen eingeben). Das Frontend weist beim Start darauf hin, wenn ein Spiel eine braucht.

WENN ETWAS NICHT KLAPPT

Nach der Installation ist nichts zu sehenKurz warten – der erste Start liest alles einmal ein. Danach im MiSTer-Menü Scripts → Frontend Start probieren.
Bei einem Spiel steht „kein Artwork“Fremdes Artwork einschalten (Seite 6), in Update All die Game Artwork DBs laden oder Boxarts nachladen.
Scrollen ruckeltMiniaturen vorbereiten laufen lassen. Auf HDMI hilft auch Menü-Auflösung: halb.
Neue Spiele fehlenDer ROM-Wächter meldet sich meist von selbst. Sonst Wartung → Spieleliste neu einlesen.
Ein Spiel startet nichtIst der passende Core installiert? Core-Übersicht und Cores: Fassung je System zeigen es; bei Computern der Computer-Check.
Bild an der Röhre abgeschnittenRand seitlich und Rand oben/unten hochstellen.
Ich will zurück ins MiSTer-MenüWartung → Frontend beenden, oder F12 / Mode für das OSD.
Wie mache ich ein Update?Das Frontend meldet neue Versionen. Dann Scripts → Frontend Install einfach noch einmal ausführen – Cover, Musik und Einstellungen bleiben.
Ich will es wieder loswerdenScripts → Frontend Uninstall. Der MiSTer ist danach wie vorher.
FÜR DEN NOTFALL (PER SSH)
Wenn du dich per SSH auf den MiSTer verbindest (z.B. mit PuTTY), helfen drei Befehle:
tail -50 /tmp/frontend.log  – was das Frontend zuletzt gemacht hat
kill $(cat /tmp/frontend.lock)  – ein hängendes Frontend beenden
touch /media/fat/frontend/disable  – Autostart abschalten (Notaus)
