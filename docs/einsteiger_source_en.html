2/11  -  GETTING STARTED
github.com/dragrem2k-coder/mister-frontend Dragend v5.1 – Beginner’s Guide

WHAT IS DRAGEND?

Dragend is a menu of its own for your MiSTer. Instead of clicking through folders in the MiSTer menu, you see your games sorted by system – with cover, release year and description – and start them with one button press. When you quit a game, you are back in the frontend.
Dragend changes nothing on the MiSTer itself: no kernel, no image, no cores. It is a program that runs alongside the MiSTer. An uninstall script removes it, and everything is as it was before.
INSTALLED IN THREE STEPS
1
Download Frontend_Install.sh from the project page (right-click → Save link as).
2
Copy the file to /media/fat/Scripts/ – with WinSCP/FTP, or with the SD card in your PC.
3
On the MiSTer, run Scripts → Frontend Install. The script downloads everything else by itself, sets up autostart and reboots the MiSTer.
The very first start takes longer. The frontend reads all your games and the arcade folder once and shows its progress. After that it starts in about two seconds.
THE FIRST START: SETUP
On the first start a short setup walks you through seven questions: language, display (HDMI TV or CRT), time zone, RetroAchievements, downloading box art and game info, and then your games are found. OK moves on, Esc skips a step. Everything can be changed later – you can run the setup again at any time under System → Info → Run setup wizard again.
WHERE YOUR GAMES NEED TO BE
Exactly where the MiSTer looks for them: under /media/fat/games/<system> (for example games/SNES), on a USB drive under games/<system> or on a network share. Subfolders are fine and show up as folders in the frontend. Arcade games come from /media/fat/_Arcade.

THE MAIN PAGE

After starting you see the main page: a list of categories. What appears there depends on what is on your SD card.
Continue Playing
The game you played last and have not marked as completed yet – one press and you carry on.
Recently Played
The games you started most recently, newest at the top.
Favorites
Everything you marked with L2 / F8.
The systems
One category per system you have games for – SNES, Mega Drive, PlayStation and so on. Systems without games do not appear.
The computers
Commodore 64, Amiga 500, Amstrad CPC and DOS (ao486) – more on page 10.
Arcade
The arcade machines from the _Arcade folder, with all subfolders.
Collections
Automatic selections across all systems.
RA Achievement Hunter
Games in your collection with open RetroAchievements (if RetroAchievements is set up).
Zufalls-Zock
Can’t decide? The frontend draws three games for you to choose from – no repeats until every game has had its turn. From Dec 1 to Jan 6 it is called Wichtel-Zock.
System
All settings, statistics and maintenance – plus your scripts and the core folders. Always at the very bottom.
THE MAIN PAGE YOUR WAY
Order and hide: System → Options → Home page, or Hide this category in the context menu (X / F1). Six views (F10 / Select+Y): list, grid, gallery – and on HDMI also tile wall, dashboard and carousel.
Attract mode: leave it alone for a while and the frontend shows games with covers as a screensaver. OK starts the game shown, left/right switches the system, any other button just wakes it up. Set it under System → Options.

STARTING AND FINDING GAMES

STARTING A GAME
Open a category, pick a game, A / Enter. For systems with more than one core the frontend asks briefly: standard core, RetroAchievements core (with real achievements) or netplay core – whichever is installed. Multi-disc games are one entry in the list; you choose the disc when starting.
FOUR VIEWS FOR THE GAME LIST (F10 / SELECT+Y)
List (names on the left, large cover on the right), grid (many covers side by side), gallery (large cover with description, neighbours below) and coverflow (HDMI only: the cover in the middle, its neighbours smaller beside it). The button just tries them out; the default for everything is set under System → Display & sound → Game list view.
THE CONTEXT MENU (X / F1)
Game infoThe profile: cover, year, genre, publisher, your play time and the description on one page.
Show manualOnly if a manual for this game is on your SD card.
Favorite / completedSet and remove marks.
Core build for this gameA specific core just for this one game (if there are several).
Search, filter, letterGet to the game quickly – search also finds words in the middle of a name.
Switch viewSame as F10.
Random game / favoriteStarts a random game or a random favorite.
Hide this entryHides a game or folder. Bring it back under System → Display & sound → Hidden entries.
WHERE THE COVERS COME FROM
The frontend uses whatever it finds, in this order: your own covers, then the artwork database from Update All (/media/fat/docs, via Extra Content → Game Artwork DBs), and for the rest System → Maintenance → Download box art fetches the missing ones from the internet. Anything Update All already delivered is recognised and not downloaded again.
For smooth scrolling: run System → Options → Prepare cover thumbnails once. It scales every cover to the right size in advance – after that each cover is there instantly, even after a restart. It takes a few minutes, any button cancels it, and it continues later where it stopped.

DISPLAY & SOUND: LOOK

All settings are on the main page at the very bottom under System. An entry always shows its current value; OK switches to the next. This is the folder System → Display & sound, first part:
Menu video: HDMI / CRTFor CRT TVs: switches the MiSTer menu picture to 15 kHz. Takes effect after a restart.
Color themeThe colours of the frontend. With save as your own scheme and edit you build your own.
Boot logoWhich logo appears at start: Dragend, Cirdan, a random one each time, or plain.
FontThe frontend’s own font or one of the MiSTer fonts from /media/fat/font.
Fine detailsSmall decorations: scrollbar, accent bars, divider. Off = a calmer picture.
Background imageYour own picture instead of the dark area. Put images into /media/fat/frontend/backgrounds.
Shadow maskLays a CRT pattern over the picture – from MiSTer’s own folder /media/fat/Shadow_Masks.
Side / top-bottom marginDistance to the screen edge. Raise it if your CRT cuts off a little at the edges.
Menu resolution: full / halfHDMI only: half resolution makes the frontend faster and the picture a little softer. After restart.
Selection glowThe selection pulses gently. Off = a fixed highlight.
Shrink covers: soft / sharpSoft averages, sharp keeps the pixel look – often nicer on a CRT.
Foreign artwork/dataUse covers, year and descriptions from the Update All database. Only fills gaps, never replaces your own covers. Recommended: on.
Inherit cover from the base gameHacks and translations without their own cover show the cover of the original game.
Rule of thumb: anything marked “after restart” only changes the picture after the MiSTer restarts. Everything else takes effect immediately.

Shows whether RetroAchievements is set up, your profile (points, rank) and the popup settings. RA is set up in the MiSTer itself – the frontend only reads along.

Top 10 (most played, most started), my achievements, the trophy room, the year in review and the play diary – all from your play time.

THE COMPUTERS WITH GAMES

Since version 5.1 four home computers have their own categories on the main page – with a photo of the machine and the games on your SD card.
Commodore 64 Games from games/C64 (e.g. the One-Load collection) start directly with the C64 core.
Amiga 500 When opening it you choose: start AmigaVision (you then pick the game in the AmigaVision menu) or ADF disks, if any are installed.
Amstrad CPC Disk images from games/Amstrad with the CPC core.
DOS (ao486) The 0MHz collection for the ao486 core. If a game is missing files, the frontend tells you when starting it.
WHAT THE AMIGA NEEDS
The Minimig core, a Kickstart ROM and – for AmigaVision – the two hard disk files AmigaVision.hdf and AmigaVision-Saves.hdf. You enter them once as hard disks in the MiSTer OSD of the Amiga core. If the Amiga stops at the Kickstart screen, this is usually what is missing.
Computer check: System → Maintenance → Computer check goes through all four computers and names what is missing – core, ROM, hard disk or game files.
Keep a keyboard handy: many computer games want a keyboard (space bar, F keys, entering names). The frontend points this out when a game needs one.

WHEN SOMETHING GOES WRONG

Nothing shows up after installingWait a moment – the first start reads everything once. Then try Scripts → Frontend Start in the MiSTer menu.
A game says “no artwork”Turn on Foreign artwork (page 6), load the Game Artwork DBs in Update All, or use Download box art.
Scrolling stuttersRun Prepare cover thumbnails. On HDMI, Menu resolution: half helps as well.
New games are missingThe ROM watcher usually notices by itself. Otherwise Maintenance → Rescan game list.
A game does not startIs the right core installed? Core overview and Cores: version per system show it; for computers, the Computer check.
Picture cut off on the CRTRaise Side margin and Top/bottom margin.
I want to go back to the MiSTer menuMaintenance → Quit frontend, or F12 / Mode for the OSD.
How do I update?The frontend tells you about new versions. Then simply run Scripts → Frontend Install again – covers, music and settings stay.
I want to get rid of itScripts → Frontend Uninstall. The MiSTer is as it was before.
IN AN EMERGENCY (VIA SSH)
If you connect to the MiSTer via SSH (e.g. with PuTTY), three commands help:
tail -50 /tmp/frontend.log  – what the frontend did last
kill $(cat /tmp/frontend.lock)  – stop a frontend that hangs
touch /media/fat/frontend/disable  – switch off autostart (emergency stop)
